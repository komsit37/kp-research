# How I Use AI — Brain as a Personal Control Plane

A one-page visual map of how I use AI across three connected domains:

- **Investing** — research, screening, backtests, portfolio decisions, and monitoring
- **Personal** — family logistics, documents, purchases, bookings, and follow-through
- **Platform** — homelab operations, automation, local models, and agent improvement

The central idea is that AI is not just a chat interface. Brain turns conversations into durable context, reusable workflows, and scheduled systems so the next interaction starts ahead.
